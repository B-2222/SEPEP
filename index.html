Publish by hand

The cloud is not connected, so changes go live by pasting the file into GitHub. Takes about fifteen seconds.

  1. Hit Copy the file
  2. Click Open data.js on GitHub
  3. Select everything in the box (Ctrl+A) and paste (Ctrl+V)
  4. Scroll down, click Commit changes
  5. Wait a minute, then refresh the site with Ctrl+Shift+R

Connect the cloud

Do this once and you never touch data.js again. The Desk saves straight to the web and anyone can put in their own tips.

  1. Open script.google.com and start a new project.
  2. Delete what is in the editor. Copy everything out of apps-script.gs in the repo and paste it in.
  3. Change PASSCODE at the top of that script to your own secret word.
  4. Click Deploy → New deployment → Web app. Set Execute as: Me and Who has access: Anyone. Deploy, then allow the permissions it asks for.
  5. Copy the web app URL it gives you and paste it below.

Hit Use this URL, then go to the Publish tab and do the copy-and-paste one last time. From then on the Desk saves to the cloud on its own.
